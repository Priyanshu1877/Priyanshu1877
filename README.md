## 🚀 Featured work

### STRIVA

A fitness app for members and gym staff. I'm building the workout log, progress charts, and AI coaching alongside tools for managing gym members.

`React` · `Node.js` · `Supabase` · `Recharts`  
[Explore STRIVA →](https://stirva.space/)

### DHR SteamShed AI

How do you look up a maintenance procedure in a railway shed with patchy internet? This prototype lets you import a PDF manual and search it locally. It indexes passages in the browser and links each match to its source page.

`TypeScript` · `IndexedDB` · `Transformers.js`  
[Explore the code →](https://github.com/Priyanshu1877/Google_code_the_railway)

### Eddelact

For this client’s product launch, I built a landing page where visitors can compare features on a phone and sign up. I added event tracking so the client could see which calls to action visitors used.

`React` · `Tailwind CSS` · `Google Analytics`  
[Read the case study →](https://priyanshudev.online/case-studies/eddelact/)
